# Microservicio Sakura Inventario - Sakura Salón

## Descripción del proyecto
El microservicio de Inventario de Sakura permite gestionar y controlar los productos e insumos del salón de belleza, registrando las entradas y salidas de stock, consultando las cantidades disponibles y facilitando el control de los recursos utilizados en los servicios
